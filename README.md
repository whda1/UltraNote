### Motivation 👑
  One day, when I am jotting notes while working, I find that the notes look bad ☹️, tools like dendron cannot customize font style easily (e.g. highlight, font color,...). You may say that we can use OneNote, Notion tools, they are good when the notes are handwritten 🤌, but when i am copying and pasting a lot of code for analyze, it can be tediou. Therefore, I have created this simple but powerful and flexible note jotting application 🧠. You can suit your needs to write plugin or customize font style for your ease to use and the beauty of notes 💋.  


### Features
- Built with Lexical, a highly fast, flexible rich text editor 💪
- Allow allow highly customized font style, plugins 🔌
- Supoort of Todo list (Deploy in next release) 🛎️
- Support of Calendar (Deply in future release) 🛎️
 
### Install

    npm install

### Develop

    npm run dev

### Quickstart

    npm run make
